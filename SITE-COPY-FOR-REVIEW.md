## How to read an entry

```
**Element type**
> The exact text as it appears on the site
*Source: `path/to/file` line ~123 — DRAFT COPY - NEEDS REWRITE (marker at line 120)*
```

- **Element type** — what the text is (H1, section label, body paragraph,
  button label, form field label, and so on).
- **Source** — the file and approximate line, so an edit can be mapped back.
  Line numbers are where the string was found and may be a line or two off in
  files where a sentence wraps.
- **DRAFT COPY - NEEDS REWRITE** — whether a draft marker governs this text.
  These markers mean the words were written by Claude Code as structural
  placeholder prose and are explicitly waiting for Amy's real copy.

  *Caveat on that flag, and it matters:* it is worked out by finding the
  nearest marker in the 40 lines above the string, so it can over-reach. Where
  a marker says what it covers, **its own wording is quoted** — read that
  first. For example `services.ts` carries one marker that says it applies to
  the four service *descriptions*; the service *names* beside them are not
  draft copy, even though they inherit the flag here. When the quoted marker
  text narrows the scope, the quoted text wins.

**Where a string is not found in any source file**, it is assembled at build
time from more than one place — a name joined to a role, a date formatted from
a raw value, and so on. Those are flagged and should not be edited as if they
were a single written sentence.
